# Как запустить NovaFides в интернете

**Статус: сайт запущен — https://novafides.pro** (старый адрес novafides.vercel.app тоже работает)
- Supabase: проект «mcsm7212-art's Project» (регион us-east-1), база загружена из `web/supabase/all-in-one.sql`, адрес сайта настроен в Authentication.
- Vercel: проект `novafides`, папка `web`, ключи Supabase добавлены, защита паролем Vercel выключена (сайт открыт всем).
- Обновления публикует Claude командой `vercel deploy --prod` из корня репозитория (файлы `.vercelignore` и `.vercel/` в `.gitignore`).

- Домен novafides.pro куплен в Vercel, www перенаправляет на основной адрес.
- Почта: письма для входа отправляет Resend с адреса no-reply@novafides.pro (домен подтверждён). В Supabase настроен SMTP с ключом Resend, который может только отправлять письма с этого домена. Лимит — 100 писем в час. В письме 6-значный код и ссылка, которая работает на любом устройстве. Шаблоны: `web/supabase/templates/code.html` (вход) и `confirm.html` (первая регистрация).

Ниже — исходная пошаговая инструкция (на случай, если проект нужно создать заново).

Сайт лежит в папке `web/` репозитория. Нужны два бесплатных аккаунта: **Supabase** (база данных, вход по email, фото) и **Vercel** (хостинг сайта). Около 30 минут.

Пока ключи не подключены, сайт работает в демо-режиме: показывает примеры мастеров, а регистрация выключена.

## 1. Supabase: база данных

1. Зайдите на supabase.com → **Start your project** → войдите через GitHub.
2. **New project**:
   - Name: `novafides`.
   - Database password: придумайте и сохраните.
   - Region: **West US (North California)**, ближе всего к Bay Area.
3. Подождите 2 минуты, пока проект создаётся.
4. Слева откройте **SQL Editor** → **New query**.
5. Откройте файл с базой на GitHub: https://github.com/mcsm7212-art/maksim/blob/claude/game-style-bulletin-board-x49gde/web/supabase/all-in-one.sql и нажмите кнопку **Copy raw file** (значок с двумя квадратиками справа над текстом).
6. Вставьте в SQL Editor и нажмите **Run**. Должно появиться «Success. No rows returned». Это создаёт все таблицы, правила доступа, хранилище фото и каталог из 115 услуг. Запускать один раз.

## 2. Supabase: вход по коду из письма

1. **Authentication → Emails → Magic Link**:
   - Subject: `Your NovaFides sign-in code`.
   - Body: вставьте содержимое `web/supabase/templates/code.html`.
   - Сохраните.
2. То же самое для шаблона **Confirm signup**.
3. **Authentication → URL Configuration**:
   - Site URL: адрес сайта от Vercel (шаг 3), например `https://novafides.vercel.app`.
   - Redirect URLs: добавьте `https://novafides.vercel.app/auth/callback`.
4. **Project Settings → API**: скопируйте **Project URL** и ключ **anon public**. Они нужны на шаге 3. Ключ `service_role` никуда не вставляйте и никому не отправляйте.

## 3. Vercel: сам сайт

1. Зайдите на vercel.com → войдите через GitHub.
2. **Add New → Project** → выберите репозиторий `maksim`.
3. **Root Directory**: нажмите Edit и выберите `web`.
4. **Environment Variables**: добавьте три переменные.
   - `NEXT_PUBLIC_SUPABASE_URL`: Project URL из Supabase.
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`: ключ anon public.
   - `NEXT_PUBLIC_SITE_URL`: адрес сайта, например `https://novafides.vercel.app`.
5. **Deploy**. Через 2–3 минуты сайт откроется по адресу Vercel.
6. Если адрес отличается от того, что вы указали на шаге 2, исправьте Site URL и Redirect URLs в Supabase.

## 4. Сделать себя администратором

1. Зарегистрируйтесь на сайте своим email.
2. В Supabase откройте **SQL Editor** и выполните, подставив свой email:

```sql
update public.profiles set role = 'admin'
where id = (select id from auth.users where email = 'ВАШ_EMAIL');
```

## 5. Проверка мастеров и компаний

После шага 4 в меню сайта появится **Admin**. Там:

1. **Pros waiting**: новые мастера.
   - У каждого есть ссылка на лицензию на сайте CSLB: проверьте, что лицензия активна и имя совпадает.
   - Отметьте галочки: «License active», «ID matches photo», «Insurance seen».
   - Нажмите **Approve**. Мастер получит уведомление, профиль станет виден в поиске.
   - **Reject** с причиной: мастер увидит причину.
2. **Companies waiting**: то же для компаний.
3. **Review reports**: жалобы мастеров на отзывы.
   - **Hide review**: только если отзыв нарушает правила (не клиент, угрозы, оскорбления, личные данные, конкурент).
   - **Keep review**: для честного негатива, его не удаляют.

## 6. ИИ-проверка ответов на отзывы (по желанию)

Без неё ответы мастеров проверяются простыми правилами (оскорбления, угрозы судом, телефоны, ссылки, капс). С ней Claude дополнительно читает отзыв и ответ и мягко подсказывает, что исправить.

1. Зайдите на console.anthropic.com, пополните баланс (несколько долларов хватит надолго) и создайте API-ключ.
2. В Vercel: **Settings → Environment Variables** → добавьте `ANTHROPIC_API_KEY` с этим ключом (без `NEXT_PUBLIC_`!) и сделайте **Redeploy**.

Если ключа нет, ИИ недоступен или отвечает дольше 15 секунд, ответ проверяется только правилами: мастер никогда не застрянет из-за ИИ.

## 7. Перед настоящим запуском

- Почта и домен уже настроены (см. статус вверху).
- Бесплатный Resend отправляет до 3 000 писем в месяц и 100 в день. Когда пользователей станет много, перейдите на платный тариф Resend.

## Что уже работает

- Вход по коду из письма, без паролей.
- Регистрация клиента, частного мастера и компании.
- Техник входит в компанию по ссылке-приглашению.
- Анкета мастера в формате объявления:
  - обязательное настоящее фото мастера;
  - опыт своими словами и навыки;
  - фото своих работ в любом порядке, до 24 сразу, потом можно добавлять;
  - лицензия CSLB, районы, языки;
  - цвет рабочей одежды (тёмная одежда → медь NovaFides);
  - уровни Эконом / Стандарт / Премиум;
  - услуги со своими ценами и подсказкой рекомендуемой цены;
  - рабочие дни и часы.
- Анкета компании: лицензия, гарантия, логотип; фирменный цвет определяется по логотипу; выбор фона.
- Поиск по услугам с синонимами. Работы с разрешением или дороже $1,000 скрыты от хендименов.
- Страница мастера как объявление: фото, опыт, навыки, фото работ, цены, свободное время, отзывы.
- Уровни, счётчики работ и паспорт из 5 навыков скрыты, пока у мастера нет 20 заказов и 10 отзывов на NovaFides. Отзывы видны с первого дня.
- На каждом заказе мастер добавляет фото «до» и «после». Их видят клиент этого заказа и офис компании.
- Страница компании: команда и кнопка «Request a visit».
- Запись к мастеру на свободное время, без двойной записи на одно время.
- Запрос оценки: «Describe your job» уходит выбранным мастерам, до 3.
- Кабинет клиента:
  - статус заказа и назначенный мастер;
  - согласие или отказ при замене мастера;
  - уведомления;
  - отзыв по 5 навыкам после работы.
- Кабинет мастера: статусы «Подтвердить → В пути → Начать → Готово» и кнопка «Online now» с выбором города, где мастер сейчас.
- Карта «Online now» (раздел в меню): схема Bay Area, сколько мастеров онлайн в каждом городе. Нажатие на город показывает их список. Точное местоположение не показывается.
- Офис компании:
  - заявки и назначение техника;
  - замена техника по правилам:
    - если мастера выбрал клиент, нужно его согласие;
    - если мастера назначил офис, клиенту приходит уведомление;
  - ссылки-приглашения;
  - экран дня (кнопка «Open day board»): колонка на каждого техника с его заказами по времени и статусами, кто онлайн и в каком городе, очередь заявок без техника. Статус можно двигать прямо оттуда, экран обновляется сам каждые 30 секунд.

- Мастер и компания редактируют свой профиль. Если услугу убрать, счётчик работ по ней не теряется.
- Страница администратора: проверка мастеров, компаний и жалоб на отзывы.
- Отзывы «вслепую»: отзыв клиента публикуется, когда мастер тоже оценил клиента (или через 14 дней). Оценку клиента видят только мастера.
- Мастер отвечает на отзыв один раз, до 600 символов. После низкой оценки ответить можно через час. Проверка тона не пропускает оскорбления, угрозы судом, телефоны и ссылки.
- Жалоба мастера на отзыв уходит модератору.
- Чат клиента с мастером или с офисом компании, с фото (до 6 за раз). Если до подтверждённой записи отправить телефон, email или ссылку, показывается предупреждение и сообщение помечается.

- Три языка: английский, испанский и русский. Переключатель EN / ES / RU вверху; при первом заходе берётся язык браузера. Переведены все экраны, уведомления и названия всех 115 услуг. Тексты, которые пишут сами мастера и клиенты (опыт, отзывы, сообщения), показываются как написаны. Перевод лежит в `web/lib/i18n-dict.ts`, испанские названия услуг — в `data/services-es.json`.

- Счета: мастер или офис выставляет счёт по заказу (работа, материалы, скидка, налог на материалы), указывает, как оплатить (Zelle, ссылка на оплату картой, чек). Клиенту приходит уведомление, счёт можно распечатать или сохранить в PDF. Итог считает сервер; когда деньги пришли, мастер нажимает «Отметить оплату», и счёт больше не меняется. NovaFides деньги не принимает.

- Календарь (Мой кабинет → Календарь):
  - заказы NovaFides появляются в календаре мастера на телефоне (Google, Apple, Outlook) по секретной ссылке;
  - мастер вставляет секретный iCal-адрес своего календаря, и занятое там время исчезает из свободных окон на сайте. Сохраняется только время, без названий событий. Обновляется при каждом заходе мастера в раздел (если прошло больше 30 минут) и кнопкой «Синхронизировать сейчас».

- Визитки (Мой кабинет → Визитка):
  - короткий адрес вида `novafides.pro/max`, мастер выбирает сам; старый адрес после смены продолжает работать, так что напечатанные визитки не пропадают; служебные слова сайта (search, admin и т.п.) заняты;
  - визитка 3.5×2 дюйма в цветах мастера: фото, имя, профессия, лицензия CSLB, рейтинг, телефон (по желанию, только для печати), QR-код на страницу;
  - печать 10 визиток на листе Letter (бумага Avery 8371/5371 или типография), лицевая сторона и оборот;
  - QR-код в PNG (для телефона и Instagram) и SVG (для типографии), файл контакта vCard;
  - на странице мастера кнопки «Сохранить в контакты» и «QR-код».
  - Совет: если планируете свой домен, большой тираж печатайте после его подключения; адрес на vercel.app при этом тоже продолжит работать.

- Соцсеть внутри NovaFides:
  - **♥ Мои мастера**: клиент сохраняет мастера кнопкой ♥ на его странице. Такие мастера первые в поиске с меткой «Мой мастер». Страница «Мои мастера» показывает сохранённых, мастеров, к которым клиент записывался (сколько работ вместе, последняя работа, кнопка «Записаться снова»), и скрытых.
  - **Скрыть мастера**: он больше не показывается этому клиенту в поиске; вернуть можно в «Моих мастерах».
  - **Лента**: проверенный мастер публикует свою работу (текст и до 6 фото, до 3 постов в день, без имён и адресов клиентов). Вкладка «Новое» — все посты, «Мои мастера» — только сохранённые. Клиенты ставят 👍. Те, кто сохранил мастера, получают уведомление о новом посте. Посты видны и на странице мастера.
  - **Рекомендации коллег**: проверенный мастер на странице другого мастера нажимает «Порекомендовать» и пишет, почему доверяет (до 12 коллег). Блок «Макс рекомендует» появляется на его странице, коллега получает уведомление. Убрать можно крестиком.
  - Мастер видит, сколько человек его сохранили.
  - **Срочная помощь** на главной: спокойная карточка «Нужна помощь прямо сейчас?» с настоящим числом мастеров, готовых приехать срочно (или просто онлайн), и подсказкой про запах газа (выйти из дома, PG&E 1-800-743-5000 или 911).
  - **Срочные вызовы**: мастер в кабинете включает «Беру срочные вызовы» и по желанию указывает доплату за срочный выезд (до $500). Пока мастер онлайн, у него значок ⚡ в поиске и на странице, и он показывается на карте «Срочные вызовы» (`/online?urgent=1`). Когда мастер уходит офлайн, значок пропадает сам.
  - **Популярно сейчас** на главной: мастера с наибольшим числом выполненных заказов за 90 дней.

- **Страница мастера в «игровом» стиле**: мастер в полный рост на прозрачном фоне с подсветкой в цвет одежды, крупное имя и «МАСТЕР ПО САНТЕХНИКЕ.», уровень или значок «Мастер-основатель», цифры (отзывы, опыт, время ответа; число работ и уровень — после 20 работ и 10 отзывов), цена «От» и запись.
- **Фото в полный рост** (Мой кабинет → Профиль): мастер загружает обычное фото с телефона, фон убирается прямо в браузере (модель Google MediaPipe, фото для этого никуда не отправляется), цвет подсветки подбирается по одежде, его можно поменять. Без такого фото на странице показывается обычное фото мастера.
- Тестовые мастера (5 шт., в описании «TEST PROFILE»): `web/supabase/test-data/test-pros.sql`, удалить перед запуском — `remove-test-pros.sql`.
