# Как запустить NovaFides в интернете

Сайт лежит в папке `web/` репозитория. Нужны два бесплатных аккаунта: **Supabase** (база данных, вход по email, фото) и **Vercel** (хостинг сайта). Около 30 минут.

Пока ключи не подключены, сайт работает в демо-режиме: показывает примеры мастеров, а регистрация выключена.

## 1. Supabase: база данных

1. Зайдите на supabase.com → **Start your project** → войдите через GitHub.
2. **New project**:
   - Name: `novafides`.
   - Database password: придумайте и сохраните.
   - Region: **West US (North California)**, ближе всего к Bay Area.
3. Подождите 2 минуты, пока проект создаётся.
4. Слева откройте **SQL Editor** → **New query**. По очереди вставьте и запустите (**Run**) три файла:
   - `web/supabase/migrations/0001_init.sql`: таблицы и правила доступа.
   - `web/supabase/migrations/0002_storage.sql`: хранилище фото.
   - `web/supabase/seed.sql`: каталог из 115 услуг.

   Каждый раз должно появиться «Success».

## 2. Supabase: вход по коду из письма

1. **Authentication → Emails → Magic Link**:
   - Subject: `Your NovaFides sign-in code`.
   - Body: вставьте содержимое `web/supabase/templates/code.html`.
   - Сохраните.
2. То же самое для шаблона **Confirm signup**.
3. **Authentication → URL Configuration**:
   - Site URL: адрес сайта от Vercel (шаг 3), например `https://novafides.vercel.app`.
   - Redirect URLs: добавьте `https://novafides.vercel.app/auth/callback`.
4. **Project Settings → API**: скопируйте **Project URL** и ключ **anon public**. Они нужны на шаге 3. Ключ `service_role` никуда не вставляйте и никому не отправляйте.

## 3. Vercel: сам сайт

1. Зайдите на vercel.com → войдите через GitHub.
2. **Add New → Project** → выберите репозиторий `maksim`.
3. **Root Directory**: нажмите Edit и выберите `web`.
4. **Environment Variables**: добавьте три переменные.
   - `NEXT_PUBLIC_SUPABASE_URL`: Project URL из Supabase.
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`: ключ anon public.
   - `NEXT_PUBLIC_SITE_URL`: адрес сайта, например `https://novafides.vercel.app`.
5. **Deploy**. Через 2–3 минуты сайт откроется по адресу Vercel.
6. Если адрес отличается от того, что вы указали на шаге 2, исправьте Site URL и Redirect URLs в Supabase.

## 4. Сделать себя администратором

1. Зарегистрируйтесь на сайте своим email.
2. В Supabase откройте **SQL Editor** и выполните, подставив свой email:

```sql
update public.profiles set role = 'admin'
where id = (select id from auth.users where email = 'ВАШ_EMAIL');
```

## 5. Проверка мастеров и компаний

Пока нет отдельной страницы администратора, проверка делается в **Table Editor**:

1. Проверьте номер лицензии на cslb.ca.gov (License Search).
2. Проверка мастера: таблица **pros**, у нужной строки поставьте:
   - `status` = `verified`;
   - `license_status` = `verified`;
   - `id_verified` = `true`, если документ проверен.
3. Проверка компании: таблица **companies**, поставьте `status` = `verified`.

Только после этого мастер или компания появляются в поиске.

## 6. Перед настоящим запуском

- **Почта.** Встроенная почта Supabase отправляет всего несколько писем в час. Подключите Resend:
  - зарегистрируйтесь на resend.com и подтвердите свой домен;
  - в Supabase откройте **Authentication → Emails → SMTP Settings** и введите данные Resend.
- **Свой домен.** Купите домен (например, novafides.com) и подключите его в Vercel: **Settings → Domains**. Затем обновите адреса в Supabase (шаг 2) и `NEXT_PUBLIC_SITE_URL`.

## Что уже работает

- Вход по коду из письма, без паролей.
- Регистрация клиента, частного мастера и компании.
- Техник входит в компанию по ссылке-приглашению.
- Анкета мастера:
  - лицензия CSLB, опыт, районы, языки;
  - фото и цвет рабочей одежды (тёмная одежда → медь NovaFides);
  - уровни Эконом / Стандарт / Премиум;
  - услуги со своими ценами и подсказкой рекомендуемой цены;
  - рабочие дни и часы.
- Анкета компании: лицензия, гарантия, логотип; фирменный цвет определяется по логотипу; выбор фона.
- Поиск по услугам с синонимами. Работы с разрешением или дороже $1,000 скрыты от хендименов.
- Страница мастера:
  - паспорт из 5 навыков;
  - счётчики работ;
  - расписание на 7 дней;
  - отзывы с ответами.
- Страница компании: команда и кнопка «Request a visit».
- Запись к мастеру на свободное время, без двойной записи на одно время.
- Запрос оценки: «Describe your job» уходит выбранным мастерам, до 3.
- Кабинет клиента:
  - статус заказа и назначенный мастер;
  - согласие или отказ при замене мастера;
  - уведомления;
  - отзыв по 5 навыкам после работы.
- Кабинет мастера: статусы «Подтвердить → В пути → Начать → Готово» и кнопка «Online now».
- Офис компании:
  - заявки и назначение техника;
  - замена техника по правилам:
    - если мастера выбрал клиент, нужно его согласие;
    - если мастера назначил офис, клиенту приходит уведомление;
  - ссылки-приглашения.
