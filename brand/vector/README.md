# NovaFides — векторный логотип

Обведено по исходному логотипу владельца (`../novafides-logo-source.png`).

| Файл | Для чего |
|---|---|
| `novafides-logo-full-copper.svg / .pdf / .png` | Полный логотип (эмблема + NovaFides MARKETPLACE), медь на чёрном: сайт, презентации, соцсети |
| `novafides-logo-full-onecolor.svg / .pdf / .png` | Полный логотип в один цвет (чёрный): печать, документы, факс, штамп |
| `novafides-emblem-copper.svg / .pdf / .png` | Только эмблема, медь на чёрном круге: аватар, иконка приложения |
| `novafides-emblem-copper-transparent.svg / .png` | Эмблема без фона |
| `novafides-emblem-onecolor.svg / .pdf / .png` | Эмблема в один цвет: вышивка, гравировка, наклейки |
| `novafides-emblem-white.svg / .png` | Белая эмблема: на цветную форму, машины, тёмные фоны |
| `novafides-wordmark-copper.svg / .png` | Только надпись |

Медь: градиент #E2B58E → #B57A50 → #7E4B2D → #C08860. Для одного цвета меди: #B57A50 (Pantone ближе всего к 7516 C / 876 C металлик — уточнить у типографии).

Для вышивки и печати используйте одноцветные SVG или PDF. Это автоматическая обводка: перед подачей на товарный знак или крупной печатью стоит показать файл дизайнеру для финальной шлифовки контуров.
