# Созвездие — доска квестов

Доска объявлений в стиле компьютерной игры. Заказчик публикует квест (заказ), а исполнители-герои откликаются. Каждый герой выглядит как персонаж из игры: у него есть уровень, опыт, рейтинг, достижения и «созвездие навыков» (скорость, качество, пунктуальность, общение).

## Что уже работает (прототип)

- **Доска**: лента квестов с фильтром по категориям.
- **Герои**: каталог исполнителей с сортировкой по рейтингу, уровню и цене.
- **Комната героя**: профиль исполнителя — это комната-обсерватория, которую можно осматривать, листая пальцем. В окне видно созвездие навыков, на стене висят фото работ («до/после» с ползунком), на доске приколоты цены и купоны со скидками, на столе лежит книга отзывов, на полке стоят награды, а календарь и часы показывают свободное время для записи. Кнопка «≡» открывает классический вид списком.
- **Отклики**: под своим квестом видны все откликнувшиеся герои.
- **Сравнение**: можно наложить созвездия 2–4 героев друг на друга и посмотреть таблицу, где отмечено, кто в чём лучший.
- **Найм**: после найма показывается праздничный экран с салютом.
- **Оценка**: после выполнения заказчик оценивает каждый навык. Созвездие героя меняется, герой получает опыт и может повысить уровень.
- **Создание квеста**: после публикации приходят отклики. В прототипе их имитирует сама страница.

Данные хранятся в браузере (localStorage). Сервера пока нет.

## Как запустить

Откройте `index.html` в браузере. Сборка не нужна.
